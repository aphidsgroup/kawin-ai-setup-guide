What this demonstrates
A cheap API can be dramatically cheaper than maintaining a cloud GPU.
A cloud RTX 3090 or 4090 may become economical compared with premium APIs.
An A100 or H100 requires high utilisation to make financial sense.
A cloud GPU does not include the intelligence of Claude, GPT or Gemini automatically; it only provides hardware on which an open model must be deployed.
Deployment, monitoring, updates, storage and failures must also be considered.

Best overall structure
A financially sensible setup would be:
Use DeepSeek V4 Flash, GPT-5.6 Luna or Mistral Small 4 for repetitive high-volume tasks.
Escalate coding and planning to GLM-5.2, Gemini 3.6 Flash, GPT-5.6 Terra or Claude Sonnet 5.
Use Claude Opus 5, GPT-5.6 Sol or Claude Fable 5 only when the lower-cost models cannot solve the task reliably.
Rent a cloud GPU only for open-weight models, experiments, privacy-sensitive work or continuously utilised inference.
Consider purchasing a local NVIDIA workstation only after the recurring cloud and API bill consistently approaches the monthly ownership cost.
The strongest cost-saving method is therefore intelligent model routing, not automatically replacing every paid API with an expensive local or cloud GPU.
